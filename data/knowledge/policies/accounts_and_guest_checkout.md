# Accounts and Guest Checkout

Effective date: January 1, 2026.

## Guest checkout

You can buy without creating an account. To check the status of a guest order, the assistant sends a one-time code to the email address or phone number on the order.

## One-time codes

- A code is valid for 10 minutes.
- You have 3 attempts to enter it.
- After 3 wrong attempts, you must wait 15 minutes before requesting a new code.
- BuyWise staff will never ask you to read a code out to them.

## Accounts

With an account you can see all your orders, save addresses and chat with the assistant without verifying each time. If you start chatting as a guest and then sign in, your conversation continues.
